# L150 Pro 四驱版风险场移植

目标硬件是轮趣 L150 Pro 四驱版和车载镭神 N10P 激光雷达。首版目标包括风险值和热图、告警、减速、停车和绕障。当前仓库中的设备接入代码面向参赛版 TCR300，车载适配待实现。

## 复用与适配

| 环节 | 参赛版 | 车载版 |
| --- | --- | --- |
| 雷达输入 | TCR300 经 TCP 提供目标位置、速度 | 对接 N10P 扫描数据，标定雷达相对车体的位置和朝向 |
| 风险计算 | 按距离、闭合速度与径向近似碰撞时间计算目标强度，叠加成二维风险网格 | 先用障碍位置生成近场风险，再用连续扫描与车体运动估计补充速度和碰撞时间 |
| 显示与告警 | 浏览器显示风险网格和等高线 | 复用网页可视化，记录风险值、观测时间和数据有效状态 |
| 底盘执行 | 道路观测 | 走原厂速度控制接口，分阶段验证减速、停车和绕障 |

风险计算核心在 [risk-field.engine.ts](../sentinel/sentinel-backend/src/engines/risk-field.engine.ts)，实时数据转换和有效期处理在 [risk.ts](../sentinel/sentinel-backend/src/live/risk.ts)。车载网格范围、分辨率、数据超时和制动参数需要结合车速、探测范围、实测延迟及停车距离确定。

## 实车验证顺序

1. 用原厂工程或镭神驱动取得扫描数据，观察车体前后左右的障碍是否映射正确，验证扫描中断时的状态变化。
2. 联调近场风险值、热图和告警，记录观测时间与输出延迟。
3. 在低速下验证减速、停车及雷达掉线时的停车行为。
4. 验证候选绕障路径上整车所需的通行空间，检查绕障和不可通行时的停车行为。

烧录前需核对随车原厂工程、主控与连接方式、原厂固件恢复方法、雷达接入、编码器反馈和四驱电机控制接口。雷达软件可参考 [镭神 N10P 驱动](https://github.com/Lslidar/Lslidar_ROS1_driver/tree/M10P/N10P)，底盘软件以随车资料为准。
