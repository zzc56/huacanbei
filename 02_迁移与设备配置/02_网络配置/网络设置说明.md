# 新电脑的雷达、摄像头网络

适用于 Windows 10/11 自带的 Windows PowerShell 5.1。先解压整个迁移包，再运行脚本；不要在 ZIP 内直接双击。

## 接线

雷达、摄像头、电脑的有线网口，分别用三根网线接同一交换机。雷达和摄像头分别供电。电脑可同时用 Wi-Fi 上网。

## 设置

1. 可先双击 **04_预览设置不修改.cmd**，选择接交换机的实体有线网卡，查看当前状态和计划；这一步不改设置。
2. 双击 **01_设置设备网络.cmd**。在 Windows UAC 提示中允许管理员权限。
3. 按名称、型号、连接状态确认接交换机的网卡，并输入其编号。USB 有线网卡也可以；工具会排除 Wi-Fi 和常见虚拟网卡。
4. 阅读原配置。若已有默认网关，会多一次 `KEEP` 确认；最终输入 `APPLY` 后才设置。
5. 该网卡添加 `192.168.10.100/24` 和 `192.168.1.100/24`。不主动删除原有地址，不新增网关、DNS，不更改其他网卡。
6. 设置后检查表格：雷达 `192.168.10.123:50000`、摄像头 `192.168.1.11:80`，`Connected=True` 表示端口可达。

**添加静态 IPv4 会停用所选网卡的 DHCP。** Windows 可能清除该网卡原来的动态租约地址、动态网关。如果网卡原来用于上网，应确认可改变它，或换独立 USB 有线网卡。若设备局域网已有其他设备使用 `.100`，先排除冲突再设置。

备份在本目录 `backups`，包含所选网卡的 GUID、原 DHCP、IP、默认网关、DNS 模式与服务器列表，不包含设备登录密码。它只用于这台新电脑的原配置恢复，不能拿到另一台电脑恢复。

## 日常检查

双击 **02_只读检查网络.cmd**，选择同一有线网卡。它只查看网卡并测试设备 TCP 端口，不登录设备、不改设置。

雷达已被上位机连接或限制并发连接时，额外测试可能失败；可以先在上位机点“中止”后复查。摄像头 RTSP 554 可达也不等于已取得可播放地址或账号。

## 恢复原网络

双击 **03_恢复原网络.cmd**，允许管理员权限，选择本电脑第一次设置前生成的备份，确认后输入 `RESTORE`。重复运行设置时，如果两个地址和静态模式已齐全，工具不重复修改，也不会产生新的备份。

- 工具校验电脑名与网卡 `InterfaceGuid`，不按旧编号猜测网卡。
- 只删除本次新增、备份之前不存在的上述两个地址；不主动删除其他地址。
- 原来开 DHCP：恢复 DHCP；DNS 按原来自动或静态模式恢复。重新获得的动态地址、网关可能与备份不同。
- 原来用静态 IP：保留原有配置，并补回缺失的原静态地址和默认网关；不会覆盖后来变化的掩码。
- 若手动改过网卡、换过 USB 网卡、重装过驱动或系统，使 GUID 改变，工具会停止，需人工核对。

## 命令行参数

在本目录打开 Windows PowerShell：

```powershell
# 先预览。把 7 改成屏幕中接交换机网卡的实际编号。
.\Set-RadarCameraNetwork.ps1 -InterfaceIndex 7 -DryRun
# 只读检查
.\Check-RadarCameraNetwork.ps1 -InterfaceIndex 7
# 指定备份并预览恢复，不修改
.\Restore-RadarCameraNetwork.ps1 -BackupFile '.\backups\实际备份文件名.json' -DryRun
```

设置和恢复出错时，保留窗口中的错误及备份文件，不要反复选择其他网卡尝试。本工具不控制雷达或摄像头内部 IP，也不设置摄像头时间、账号或密码。
