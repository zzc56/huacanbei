# 雷达＋摄像头迁移使用说明

## 先做什么

把整个“雷达摄像头迁移包_2026-10-11”文件夹复制到另一台 Windows 10/11 64位电脑的本地硬盘，并完整解压。不要在ZIP或U盘里直接运行。建议放在用户有写入权限的目录，例如 D:\RadarKit；无需沿用本机的 E:\car 或 ASUS 用户名。注册虚拟摄像机之后保持包的位置固定。

包内带 TCR300 V2.0.7 摄像头修复版、OBS 32.2.2 便携程序、两个OBS场景、双网段设置和恢复工具、微软VC++运行库、摄像头发现工具。没有带历史雷达CSV、录像、浏览器登录状态或摄像头密码。

## 1．接线和供电

雷达、摄像头、电脑有线口分别用网线接入交换机，三根网线。雷达和摄像头各自接原有合适电源。交换机普通网口不等于PoE供电；目前沿用已经跑通的单独供电方式。电脑没有RJ45时使用USB有线网卡。

## 2．准备运行环境

先双击“检查迁移包.cmd”。缺VC++运行库或报VCRUNTIME/MSVCP错误时，打开“04_运行库\安装运行库.cmd”，按微软安装界面安装或修复。离线安装器已验证微软签名，版本14.51.36247.0。雷达软件使用.NET Framework 4；Windows 10/11通常有.NET Framework 4.8，如运行报.NET错误需检查该Windows组件。

首次使用便携OBS，右键根目录“注册虚拟摄像机.cmd”→以管理员身份运行。它调用OBS自带官方脚本，注册32位和64位组件。TCR300软件是32位，所以32位注册也需要成功。若新电脑已有能工作的OBS虚拟摄像机，官方脚本会跳过已有注册；不要随意卸载它。若提示已注册但上位机找不到，检查旧OBS是否已被移动/删除，优先修复那套安装。便携OBS方案参考 https://obsproject.com/kb/portable-mode 和 https://obsproject.com/kb/virtual-camera-troubleshooting 。

## 3．设置新电脑的有线网卡

打开“02_网络配置\01_设置设备网络.cmd”，在表格中选择真正接交换机的有线网卡编号。工具显示原配置，确认后才执行，自动备份该电脑该网卡状态。不要照搬旧电脑的网卡编号10。

| 设备 | 地址／设置 |
|---|---|
| 雷达 | 192.168.10.123，TCP 50000，TCR300-Self |
| 摄像头 | http://192.168.1.11/ |
| 新电脑有线口第一个IPv4 | 192.168.10.100，掩码255.255.255.0 |
| 新电脑同一个有线口第二个IPv4 | 192.168.1.100，掩码255.255.255.0 |

这两个地址用于专用采集有线口，不另填网关或DNS；Wi-Fi可以继续上网。原网卡若有默认网关、DHCP租约，工具会提醒影响。只读检查用“02_只读检查网络.cmd”；预览设置用“04_预览设置不修改.cmd”。恢复用“03_恢复原网络.cmd”，选择本电脑本次设置前的备份。摄像头IP改变时也要调整电脑相应网段。

## 4．先确认摄像头画面

双击“打开摄像头网页.cmd”，在新Edge窗口里登录摄像头自身的设备账号和密码，确认预览有实时画面。这里不需要登录睿博士手机账户。迁移包不保存密码。浏览器保持该摄像头标签页，不要最小化窗口；被OBS等窗口遮住通常仍可采集。

## 5．启动OBS并重新选择窗口

双击“启动OBS.cmd”。包内OBS使用独立便携配置，不覆盖新电脑现有OBS配置。若已有OBS运行，先自行退出再打开本包。默认画布/输出1920×1080、30fps，软件x264编码，混合MP4录像；默认不采集桌面或麦克风音频。

选场景“摄像头视频（重新裁剪）”，双击来源“摄像头网页（重新选择窗口）”，重新选新电脑的“IP摄像头 - Microsoft Edge”窗口。不要选ChatGPT或雷达上位机。确认OBS出现摄像头画面。

## 6．裁剪网页边框

新电脑分辨率、Windows缩放、Edge大小和网页布局可能不同，所以默认场景保留全部窗口。先固定Edge窗口大小。选中来源→Ctrl+R重置→Ctrl+F等比适配；Ctrl+E打开编辑变换，填四边裁剪值，关闭后Ctrl+F等比适配。也可按住Alt拖动来源边缘裁剪。裁剪后确认完整监控图像四角仍在。

另有“本机裁剪参考”场景：原始来源2560×1528，左29、右52、上226、下142像素，仅供相同窗口布局参考，不保证新电脑可直接复用。本机效果见“05_说明与参考\本机裁剪效果.png”。完整保留图像时上下黑边可以保留。改变浏览器大小或缩放后重新核对，不用Ctrl+S拉伸。

若使用新电脑已安装的OBS，可在“场景集合→导入”选择“05_说明与参考\OBS_可导入场景.json”，然后手动设1920×1080、30fps及录像路径。此时包内启动器管理的便携录像目录不适用于你现有的OBS。

## 7．雷达与视频预览

OBS右侧点“启动虚拟摄像机”，按钮显示“停止虚拟摄像机”说明已启动。双击包内“启动雷达上位机.cmd”。在雷达左侧视频区右键选“OBS Virtual Camera”。系统配置里选TCR300-Self、TCP、192.168.10.123、50000，再连接。请使用修复版，原版曾因摄像头格式索引错误黑屏。

## 8．保存两路数据

启动器按当天日期建立“采集数据\YYYY-MM-DD\video”和“采集数据\YYYY-MM-DD\radar\SaveData”。不依赖新电脑的盘符或用户名。雷达启动时默认关闭保存，需你每次主动开启。

雷达：系统配置→存储配置→左下角勾选框，从“关闭”变“开启”→应用。实际目标文件位于 radar\SaveData\TCR300-Self\TCP\Object。结束时先点上位机顶部“中止”，写出剩余数据，再退出。CSV约每5秒写一次；一行对应一个已处理的目标记录，含Time、ID、Rx/Ry、Vx/Vy等，不是ADC/IQ原始信号，也不保证每个空帧都有记录。无车辆时可能只有3字节UTF-8 BOM空文件。

视频：在OBS右侧点“开始录制”，结束点“停止录制”，再“文件→显示录像”检查结果。虚拟摄像机本身不会保存视频。先录10秒验证能打开、图像完整，再正式采集。软件编码若明显掉帧，可在新电脑确认显卡后改兼容的硬件编码。

## 9．时间与道路测试

新电脑时间保持北京时间UTC+8。摄像头网页“配置”里找到时间设置，校到电脑时间并保存，验证画面OSD。先前摄像头时钟落后电脑数天，未确认已改好。摄像头OSD、OBS文件名与雷达Time不是自动精确同步；研究用途还需要测量/标定网络、解码和采集延迟。NTP需有可达的服务器，孤立交换机不自动提供互联网。

当前已验证摄像头网页→OBS→修复版左侧预览，以及保存开关生成文件。室内无车辆，尚未验证真实车辆目标CSV。道路采集时雷达竖直稳定安装、天线面朝目标、LED位于下边；有移动目标点后录20～30秒，再检查CSV和视频。

## 常见问题

| 现象 | 先检查 |
|---|---|
| 摄像头网页打不开 | 供电、交换机灯、电脑192.168.1.100、摄像头实际IP；辅助工具EasySearch可发现设备 |
| 雷达连不上 | 电脑192.168.10.100、雷达192.168.10.123:50000、旧电脑上位机是否仍占连接 |
| OBS窗口列表没有摄像头 | 摄像头网页放独立Edge窗口，保持打开且不最小化，再重选 |
| 左侧只有黑屏 | OBS先有画面并启动虚拟摄像机，32位注册成功，再启动修复版选择OBS |
| CSV不断生成但没有记录 | 先看右图是否有移动目标；室内没车不能证明采集损坏 |
| 改了日期却还不对齐 | 校时只修时钟，仍需测量两路延迟 |

## 无线和开发

这台已购Wi-Fi版摄像头可以尝试接入路由器Wi-Fi，电脑在可互通的同一局域网访问；具体配置需在睿博士或摄像头网页确认，IP可能改变。雷达接口是RJ45/RS485，文档不表明有内置Wi-Fi；要让电脑少一根网线，可把交换机接路由器LAN，电脑连该路由器Wi-Fi，但必须配置可达的网段，不能直接照搬本包仅有线口的双IP设置。4G版能力不能由同一商品介绍推定到你买的Wi-Fi版。

现有TCR300包只有编译后的EXE/DLL，没有.sln/.csproj源码工程。小修补已实现，但大型功能建议获得厂商源码/SDK，或新建自己的研究上位机。开发需要匹配TCR300固件的TCP协议/SDK及目标字段/时间语义；摄像头可查P6S Windows/Linux SDK或ONVIF/RTSP实际能力。P6S文档是摄像头侧接口，不是TCR300协议。可优先做原生取流、两路采集日志和时间校准、轨迹回放，再加入经验证的风险场与预警模块。资料：https://docs.p6sai.com/docs/ 、http://docs.p6sai.com/docs/cn/device/SDK_FAQ/FAQ/SDK/SDK-3.html 、https://www.nanoradar.cn/Products_1/19.html 。

## 包的状态

本机程序与组件已复制并校验；OBS场景是可迁移模板，当前运行中的OBS未被关闭或改写。没有在另一台电脑上执行网卡设置、注册组件或录像测试，需按上面步骤完成。网络脚本已作语法和只读路径审查，不曾在本机执行网络变更。文件校验清单用于刚解压时检查完整性，使用后配置/数据库可能正常改变。
